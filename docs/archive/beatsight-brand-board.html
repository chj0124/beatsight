时值节拍器

把抽象的「时值」翻译成看得见的「长度」——块有多宽，音就有多长。一套为吉他练习者而生的深色沉浸视觉系统。

01

设计原则

视觉系统的四条底层约定——它们同时是产品观，也是工程纪律，贯穿于每一处颜色、字号与控件。

时值即长度

核心视觉隐喻：格子宽度与音符时值严格成正比（1 拍 = 48 tick）。一切图形服务于「眼睛先学会，耳朵就跟上」。

语义分色

颜色是信息而非装饰：绿只留给「进行中」，琥珀标记乐谱，选中态与发声态严格分色——一色一义，互不抢戏。

本地优先

单文件、零依赖、无账号、无上传。视觉同样克制：无外部字体请求、无重资源，所有图形由内联 SVG/CSS 完成。

同源 token

所有尺寸与颜色收敛为 CSS 变量并单一来源——「改一处，跟多处」。自验闸门（node tools/check-all.js）保证系统不漂移，步数以命令末尾自打印的实跑结果为准。

排版要点 · Rules
  • · 内容最大行宽 850px（--max-w），窄屏自动分片
  • · 正文行高恒 1.5；标签类收紧到 1.1–1.25
  • · 数字一律 mono + tabular-nums，禁止比例数字抖动
  • · 滚动条槽恒定预留，面板开合不引发布局横移
  • · 焦点环 2px 功能绿 + 2px 偏移，键盘可达

✓ 推荐

  • 「正在发声」只用功能绿；乐谱标记只用琥珀；两者同框互不借用
  • 选中态用中性深灰家族（--sel-*），与发声态明确区分
  • 深色场景下强调色用近白（--peak），层级靠明度而非新增色相
  • 新增尺寸先进 CSS 变量，保证「改一处、跟多处」
  • 小字（10–11px）保持 --t3 以上明度，守住 AA 对比底线

✕ 避免

  • 不要给「选中但未播放」的控件上绿色——用户会以为它在响
  • 不要引入第七种强调色；八度三色已占用暖/中/冷三席
  • 不要用 Inter 渲染 BPM 等数字——非等宽会逐位漂移
  • 不要给内容容器用全胶囊圆角；999px 是控制族专属
  • 不要在物料上放外部字体 / 图片请求——违背零依赖承诺
