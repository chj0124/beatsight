# BeatSight 时值节拍器

> 吉他练习用的节奏可视化节拍器 —— 把抽象的「时值」翻译成「长度」，一眼看懂节奏型。

单文件、零依赖、双击即用的网页应用（v1.4 起在线版支持 PWA 离线安装——`manifest.webmanifest`/`sw.js`/`icon.svg` 三个独立文件只服务在线部署，不影响本地单文件直开）。设计目标：保留传统节拍器的可靠性，同时解决"听不出附点/切分"的自学痛点。

## 快速开始

- **在线使用**：https://beatsight-34873.app.workbuddy.host/（支持 PWA 安装到桌面/主屏幕，装完可离线使用）
- **本地使用**：双击 `index.html`（任意现代浏览器，手机浏览器同样适用）
- ⚠️ **两种用法的数据不互通**：`file://` 与 `https://` 是不同 origin，`localStorage` 不共享。在本地攒的预设，打开在线版会看到空的——迁移请用「导出预设」/「导入预设」
- 首次发声需先点击页面任意位置（浏览器音频策略），空格键开始/停止

### 核心交互细节

- **时值可视化**：音符块宽度与时值严格成正比，同屏 4 小节滚动
- **弹跳球**：球在相邻发声点之间跳重力抛物线，落点即下一颗音的真实发声时刻——看着球下落提前出手，如同跟指挥棒；跳距与时值成正比，静音小节照跳（视觉兜底），休止符长跳跨过
- **十六分小格**：每个音符块内按十六分等分刻度，跑完一格四边亮一下（绿块上闪白光、白/暗块上闪绿光）
- **当前高亮**：正在弹的音符块白色进度填充 + 绿色描边提示，弹完定格纯白——四种时值观感一致，绿色只做功能强调
- **静音拍训练**：每 4 小节静音第 4 小节，强制内心数拍
- **变速训练**：训练模式开启后每次播放从起始 BPM 起步，每练满 N 小节自动 +步长爬坡（不打断播放），到目标速度练满一级自动停止；练过即记住进度，「继续上次 · 从 X BPM 接着练」一键接续（v1.4）
- **练习统计**（v1.4/v1.6）：有效练习（≥30 秒）停止时自动入账；顶栏「练习统计」看本周时长 / 连续天数 / 速度纪录 / 累计场次 + 近 7/30 天柱图 + 各节奏型速度纪录，记录可导出 JSON 备份
- **7 天爬升计划**（v1.5）：按当前起始/目标 BPM 一键生成 7 段排程，「开始今日训练」一键开练；练到当天目标自动推进，缺练顺延不补卡
- **后台保活**（v1.4）：训练模式区的开关，wakeLock 防息屏 + 静音循环音频兜底（iOS）；默认关，播放中打开立即生效
