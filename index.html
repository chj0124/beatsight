07How to use

三步上手

  1. 右侧「节奏型」里选一个（或点「编辑节奏型」自己画一个）
  2. 设速度：BPM 数字可以点开直接输入，也可以连点「TAP 测速」凭手感敲出来
  3. 按播放（或空格键）开始——浏览器的首次点击是在解锁音频，属正常现象
这个应用的核心是「把节奏画出来」——不只看拍子，还看每个音有多长。

画面怎么看

  • 一行 = 一小节（手机竖屏等窄屏下会自动拆细：一行只画半小节、甚至每拍一段—— 格子更宽更好读，拆分的边界仍落在整拍上；跨行的长音会画成两段、断开的那侧是虚线边）； 同屏画几行由「同屏行数」档位决定（1–4 行）。 曲式模式下这几行是「这首歌正在弹的那几小节」，跟着播放整页往前翻 （会跨段——某一行的型与上一行不同是正常的，那是歌曲自己的进行）， 读到页末还会把第 1 行临时换成「下一小节 · 型名」提前备型——预告行只在 2 行及以上出现， 1 行档就是干净的一行 = 正在弹的这一个小节； 预设模式下这几行是「当前这个型的连续几小节」：型比行数短就绕回重复铺满 （1 小节的型配 4 行档 = 同一小节铺 4 行），型比行数长就按行数翻页
  • 格子的宽度 = 音符的时值：越宽的音符越长。休止符是等长的空白占位（不发声，但占着位置）
  • 底部 1 e & a 是拍内座次，帮你对齐十六分位置；跑道亮边 = 换拍
  • 弹跳球预告「何时」落拍：跳得越高说明离下一颗越久；球会提前起跳落在下一个音上
  • 播放头扫过的位置就是「现在」，已弹过的格子会亮白
  • 画面动画由音频时钟驱动——以声音为准对齐画面，声画偏差 < 16ms

先试这几个开关

  • 静音拍：每 4 小节的最后一小节不发声，逼你靠内心数拍。练节奏不稳特别有效
  • 变速训练：设好目标速度与「每几小节加多少」，从你现在弹的速度起步自动加速，爬到目标自动停（不用自己按）
  • 预备拍：点播放后先数几拍再进正拍

全部控制项

速度 BPM
30–240。滑杆下面的常用档是 60 / 72 / 84 / 96 / 120
拍号
2/4 到 7/4。切到奇数拍（5/4、7/4）会多出一行「重拍分组」，选 2+3 还是 3+2
Swing
把每拍后半的八分往后推，做出摇摆感。只改发声时机，不改时间轴
音色 / 音量
电子 / 木鱼 / 鼓组（都是程序合成，不占体积）。节拍 = 节拍器那一下（每拍拍点 / 预备拍 / 歌词提示音）；扫弦 = 弦区扫弦声（只作用于带扫弦记谱的节奏型）。两条各调各的：把「节拍」拉到 0，扫弦照样响。重拍增强 = 重拍比正拍响多少（两条声部都受影响）
延迟补偿
蓝牙耳机 / 无线音箱通常有 100–300ms 输出延迟——声音比画面晚到。补偿把所有声音提前相应毫秒发出（设置里调，带「跟着敲」的校准向导）；可按设备存多套配置，换耳机时切换、上次用的会被记住
弹跳球
关掉就只剩声音；静音拍训练时建议留着——静音的那小节里球是唯一的节拍来源
后台保活
切到别的标签页或手机息屏时尽量不被系统暂停（耗电换连续，按需开）

训练模式

  • 变速训练：三项参数——目标速度 / 每级加多少 / 每几小节加一级。从开播那一刻的速度起步往上爬，到目标自动停
  • 听辨训练：先听 2 小节，再从三张只给记谱、不给名字的候选里选——练的是耳朵，答案作答后才揭晓。专治「听不出附点和切分」

曲式编排（预设卡片里）

  • 整首连播：预设库「示例曲」分组顶部那个按钮——一键按原曲顺序从第 1 段走到第 10 段， 放完自动从头再来，不用打开编排面板。按钮旁边的说明写着现在播到第几小节
  • 播放范围滑块（在「整首连播」下面）：按小节拖两个滑块自由选范围 （刻度就是小节，轨道上的细刻度线是段边界）——范围可以从段中间开始/结束，比如 「第 5–12 小节」就只练副歌里那几小节。读数行会把它翻译成 「第 5–12 小节 · 副歌 → 桥段 · 共 8 小节」；两个滑块拖到重合 = 只循环这一个小节 （磨"老是弹不顺的那一小节"），想循环一整段就拖出该段的起止小节。 它和编排面板里的「起 / 终」是同一份范围，两边改哪边都同步。 注意：滑块表示的是范围不是播放位置——"现在在第几小节"看上面那行说明
  • 想单练某一个节奏型，直接点侧栏里那个型即可退回单型循环——「整首连播」与「点某个型」是两个对等的入口
  • 想换某一段用哪个节奏型：进「编排曲式」，在该段那一行点「换」——侧栏上的「切换节奏型」 胶囊条已删除（它的候选与「扫弦」区里的条目完全重复）
  • 一首歌 = 若干段，每段 = 若干块，一块 = 一个节奏型 × N 遍
  • 「起 / 终」定播放范围 +「范围循环」= 只反复练副歌；「◀ 上一段 / 下一段 ▶」跳段： 播放中本小节播完即进入目标段；停止时点 = 改下一次播放的起点，网格与标题会立即换成那一段的节奏型
  • 整首必须是同一个拍号——混拍号会被拦下并告诉你是哪一段

自己画节奏型

  • 「编辑节奏型」里点小节选中、点下面的时值按钮加音符；每小节的时值必须刚好填满才能保存
  • 一个小节不够用就加：「＋ 在其后加一小节」会在当前小节后面插一节，内容先复制当前小节 （再点音符块库改成你要的）；「− 删当前小节」删掉它，最少留 1 小节 ——一个节奏型可以是你需要的任意长度（1–64 小节），不一定非是 4 小节
  • 扫弦方向 ↑↓ 是可选标注，只影响显示，不影响发声；字形按手部动作走（下扫画 ↑、上扫画 ↓）
  • 休止符上也能标方向 = 空扫：手在动、弦不出声，用蓝色括号画出来

数据与隐私

  • 所有数据只存在这台设备的浏览器里，不上传任何服务器
  • 清除站点数据会一并删掉自定义节奏型和曲式——重要的用「导出预设」存一份 JSON 备份
  • 若自定义预设曾因结构损坏被隔离（beatsight.quarantine），它们会一直占着本地配额； 这里可以查看条数并清理（清理不可撤销，介意的话先导出备份）

外观与辅助

主题（经典 / 观测台）与两个画面图层开关。弹跳球预告「何时」落拍，关掉就只剩声音；六线底纹只对带扫弦记谱的型有意义——不带记谱的型本来就不画六线也不画箭头，所以那个开关在那些型下会自动隐藏（点了没反应比没有还糟）。
背景壁纸
遮罩深浅 55%
出厂自带一张默认背景图（可商用素材）。支持换成自己的 JPG / PNG / WebP：图片会缩到长边 1600 像素后存在本机（原图不保留、不上传、不联网）；铺满屏幕不变形，只在卡片外的留白里露出来。点「移除」后默认图也不会自己回来，想找回来用「恢复默认」；存不下时（浏览器给的本机空间约 5 MB，与预设共用）会明确提示，不会默默失败。

发声

三套音色都是程序合成（不占体积、没有采样文件）。音量不在这里：节拍 / 扫弦 / 重拍增强三条滑杆留在主界面的状态灯下方——练习中会随时调，属高频控件。
Swing · 八分对摇摆（只影响发声时机）
音频延迟补偿（蓝牙耳机 / 无线音箱）
补偿 0 ms

蓝牙耳机通常有 100–300ms 延迟：画面上的落点到了，耳朵里还要等一会儿才听到咔嗒。补偿就是把每一颗音提前这么多毫秒发出去，让「听到的」与「看到的」重新对上（不动节奏与曲序，只改发声时刻）。点「校准向导」跟着敲八下会自动给一个建议值，再用滑杆微调到声画重合。配置只存在本机、不联网，也不进「导出全部数据」（换设备本来就该重新校准）。

数据与说明

全部数据都存在本机浏览器里（无账号、无上传）。换设备或换通道（file:// 与 https:// 数据不互通）之前，用「导出全部数据」带走整包：预设 + 曲式编排 + 歌词对齐 + 听辨战绩。导入按合并语义写回，不会覆盖本机已有的。
